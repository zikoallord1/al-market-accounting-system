# نظام الماركت المحاسبي

نظام محاسبي وإداري متكامل للمبيعات والمشتريات والأصناف والمخزون والعملاء والموردين والمالية والموظفين والتقارير والمراقبة.

## الهوية
- الاسم الظاهر: **نظام الماركت المحاسبي**
- الواجهة: العربية RTL
- التصميم: بسيط وموحد وقابل للتوسع
- المبدأ: إدخال العملية مرة واحدة ثم ربطها تلقائياً بالمخزون والحسابات والأرصدة والتقارير وسجل التدقيق.

## الوحدات الرئيسية
المبيعات، المشتريات، الأصناف، المخزون، العملاء، الموردون، المالية، الموظفون، التقارير، الكاميرات والمراقبة، الإعدادات.

## مبدأ المحاسبة
Business Event → Rules → Engine → Accounting → Balances → Reports → Audit
