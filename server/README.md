# خادم مزامنة نظام الماركت المحاسبي

خادم HTTP مستقل لنقل أحداث العمليات بين أجهزة النظام.

## التشغيل
npm run sync-server

المنفذ الافتراضي 8787.

## API
GET /health
POST /api/sync/events
GET /api/sync/events

يحفظ الأحداث في server-data/sync-events.json. الخادم لا ينشئ قيوداً محاسبية ولا يغير العمليات؛ وظيفته استقبال الأحداث، منع التكرار، وكشف تعارضات المرجع بين الأجهزة.
